# Lacewing fonts

Bundled from the Google Fonts repository on 3 November 2026:

- [Inter](https://github.com/google/fonts/tree/main/ofl/inter), regular and italic variable TrueType sources. Static instances use optical size 14 and weights 400/600.
- [Cormorant Garamond](https://github.com/google/fonts/tree/main/ofl/cormorantgaramond), regular variable TrueType source. Static instances use weights 500/600.

The matching SIL Open Font Licences are included. Static instances were produced with fontTools for compatibility with ReportLab and browsers; no font downloads are required at runtime.
